## Rebuild and export

Use the Xcode version above, the pinned Swift packages, your authorized signing identity, and the matching provisioning profile. The repository contains no private signing keys or reusable account credentials. Review package build plugins when Xcode asks.

```sh
xcodebuild \
  -project ios/App/MLXPeerApp.xcodeproj \
  -scheme MLXPeerApp \
  -configuration Release \
  -destination 'generic/platform=iOS' \
  -archivePath build/MLXPeer.xcarchive \
  archive

xcodebuild \
  -exportArchive \
  -archivePath build/MLXPeer.xcarchive \
  -exportOptionsPlist ios/App/ExportOptions-AppStore.plist \
  -exportPath build/AppStoreExport
```

`ExportOptions-AppStore.plist` names the publisher's team and the `MLX Peer App Store` profile. Forks must replace those with their own team, bundle ID and profile. Exporting creates a local artifact; it does not upload or publish it.
