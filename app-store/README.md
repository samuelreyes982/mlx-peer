## Distribution scope

The publisher's release scope is iPhone. Keep `TARGETED_DEVICE_FAMILY = 1` and both `SUPPORTS_XR_DESIGNED_FOR_IPHONE_IPAD` and `SUPPORTS_MAC_DESIGNED_FOR_IPHONE_IPAD` set to `NO`. The uploaded build 4 archive has `UIDeviceFamily = [1]`; it has no native iPad target. Apple Vision Pro availability and iOS-on-Mac availability were verified unchecked in App Store Connect on September 23, 2026. Do not enable these distribution options or add native iPad support for this release.

An iPhone-only target does not guarantee exclusion from iPad: Apple can run iPhone apps in iPad compatibility mode. [Apple's review guidelines](https://developer.apple.com/app-store/review/guidelines/#hardware-compatibility) encourage iPhone apps to run on iPad whenever possible. Do not add fictitious hardware requirements to force an exclusion. Keep the explicit [Vision Pro distribution opt-out](https://developer.apple.com/help/app-store-connect/manage-your-apps-availability/manage-availability-of-iphone-and-ipad-apps-on-apple-vision-pro) in place before submission.

## Rebuild and export

Use the Xcode version above, the pinned Swift packages, your authorized signing identity, and the matching provisioning profile. The repository contains no private signing keys or reusable account credentials. Review package build plugins when Xcode asks.

```sh
xcodebuild \
  -project ios/App/MLXPeerApp.xcodeproj \
  -scheme MLXPeerApp \
  -configuration Release \
  -destination 'generic/platform=iOS' \
  -archivePath build/MLXPeer.xcarchive \
  archive

xcodebuild \
  -exportArchive \
  -archivePath build/MLXPeer.xcarchive \
  -exportOptionsPlist ios/App/ExportOptions-AppStore.plist \
  -exportPath build/AppStoreExport
```

`ExportOptions-AppStore.plist` names the publisher's team and the `MLX Peer App Store` profile. Forks must replace those with their own team, bundle ID and profile. Exporting creates a local artifact; it does not upload or publish it.
